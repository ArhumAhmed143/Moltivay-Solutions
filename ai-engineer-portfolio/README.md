# AI Engineer Portfolio // Futuristic 3D Cyberpunk Edition

A state-of-the-art, dark-themed portfolio for an **AI Engineer & Vision-Language Architect** built with modern frontend engineering principles.

## Tech Stack & Architecture
- **HTML5**: Semantic, accessible markup.
- **Tailwind CSS**: High-tech color system (`#0a0a0a` Deep Black, `#00f3ff` Neon Cyan, `#bc13fe` Electric Purple).
- **Three.js (r128)**:
  - Fullscreen dynamic 3D Neural Particle Network reacting to cursor movement and scroll depth.
  - Holographic 3D Wireframe Globe with multi-axis orbital rings and floating glowing nodes.
  - Ambient neural token data streams in the footer.
- **GSAP 3.x + ScrollTrigger**:
  - Smooth 3D parallax and section entrance reveals.
  - Word-by-word scroll illumination of the engineer's manifesto.
- **Web Audio API**:
  - Procedural cybernetic audio feedback (clicks, blips, chirps, success chimes) with full user mute control.
- **Interactive Terminal CLI (`~`)**:
  - In-browser cybernetic terminal supporting commands like `help`, `benchmark`, `models`, `specs`, and `hire`.

## Quick Start
To view the portfolio:
1. Double-click [index.html](file:///c:/Users/dell/Desktop/Moltivay%20Solutions/ai-engineer-portfolio/index.html) in your browser of choice (Chrome, Edge, Brave, Safari, Firefox).
2. Or serve it via any static server:
   ```bash
   npx serve ai-engineer-portfolio
   ```

## Directory Structure
- `index.html`: Main portfolio landing page.
- `css/style.css`: Custom animations, glassmorphism, neon glows, scanlines, and HUD components.
- `js/three-scene.js`: Three.js WebGL scenes (Background neural net, Hero globe, Footer stream).
- `js/audio.js`: Procedural Web Audio API sound synthesizer.
- `js/terminal.js`: Interactive cyber CLI terminal emulator.
- `js/main.js`: GSAP ScrollTrigger controller, custom cursor, 3D card tilt, benchmark switcher, and live OCR simulator.
